# ReneWind: Wind Turbine Failure Prediction Using Neural Networks

Machine learning project using neural networks to predict wind turbine generator failures and support predictive maintenance through high-recall classification modeling.

---

## Project Overview

This project develops neural network classification models to predict wind turbine generator failures using operational sensor data from ReneWind, a renewable energy company.

The analysis focuses on predictive maintenance by identifying potential generator failures before breakdowns occur, helping reduce operational downtime, maintenance costs, and equipment replacement risks.

---

## Objectives

- Analyze wind turbine operational and sensor data
- Build neural network classification models for failure prediction
- Optimize failure detection using recall-focused evaluation
- Support predictive maintenance and operational reliability

---

## Skills & Tools Used

- Python
- Pandas
- NumPy
- TensorFlow / Keras
- Neural Networks
- Classification Modeling
- Model Evaluation
- Predictive Maintenance Analytics
- Data Visualization

---

## Key Insights

- Model 4 emerged as the best-performing neural network model.
- The final model achieved strong recall performance, effectively identifying most potential generator failures.
- The model demonstrated excellent generalization across training, validation, and test datasets.
- High precision and F1-score indicate reliable and stable predictive performance suitable for real-world maintenance applications.

---

## Business Recommendations

- Integrate the predictive model into turbine maintenance scheduling systems.
- Use model-generated alerts to support proactive inspections and reduce unexpected failures.
- Establish standardized inspection procedures for flagged turbines.
- Continuously retrain and monitor the model using updated operational data.
